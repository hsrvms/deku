# Deku Documentation

This directory contains the canonical project documentation.

## Product

- [Vision](vision.md) — enduring product intent and philosophy.
- [Roadmap](roadmap.md) — current product horizon; roadmap items are not implementation commitments.
- [Specifications](specs/README.md) — accepted release and feature requirements.
- [Architecture decisions](adr/) — durable decisions and their trade-offs.
- [Release runbook](reference/release-runbook.md) — maintainer procedure for publishing, withdrawing, and revoking Releases.

## Documentation lifecycle

Specifications define intended work; ADRs explain consequential architectural choices; guides and reference material describe supported released behavior. `CONTEXT.md` at the repository root is the canonical domain glossary.

Every accepted change must update the relevant documentation. See [`AGENTS.md`](../AGENTS.md) for the required documentation-impact review.
